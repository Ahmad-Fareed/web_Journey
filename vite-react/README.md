# Vite React - First React App

A beginner-friendly React application built with Vite. This is my first React project exploring the fundamentals of React development.

## Features

- ⚡ Fast development with Vite
- ⚛️ React 19.2.6 with React DOM
- 🔍 ESLint configured for code quality
- 🚀 Hot Module Replacement (HMR) for instant updates
- 📦 Optimized production builds

## Tech Stack

- **React** - JavaScript library for building user interfaces
- **Vite** - Next generation front-end build tool
- **JavaScript (ES6+)** - Modern JavaScript features
- **CSS** - Styling

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone or navigate to the project directory:
```bash
cd vite-react
```

2. Install dependencies:
```bash
npm install
```

### Available Scripts

- `npm run dev` - Start the development server (runs on http://localhost:5173)
- `npm run build` - Build the project for production
- `npm run preview` - Preview the production build locally
- `npm run lint` - Run ESLint to check code quality

## Project Structure

```
vite-react/
├── src/
│   ├── App.jsx          - Main React component
│   ├── main.jsx         - React entry point
│   └── index.css        - Global styles
├── index.html           - HTML template
├── vite.config.js       - Vite configuration
├── package.json         - Project dependencies
└── eslint.config.js     - ESLint rules
```

## Development

To start developing:

```bash
npm run dev
```

The app will automatically reload when you make changes to the code (HMR).

## Building for Production

Create an optimized production build:

```bash
npm run build
```

Preview the build locally:

```bash
npm run preview
```
