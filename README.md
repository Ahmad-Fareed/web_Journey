## ⚡ Quick Start

Most projects are static HTML/CSS/JS and can be run directly in a browser:

```bash
# Clone the repository
git clone https://github.com/Ahmad-Fareed/web_Journey.git
cd web_Journey

# Open any project
# Option 1: Open directly
start Netflix\ Clone\(HTML,CSS\)/index.html

# Option 2: Use VS Code Live Server (recommended)
code .
# Right-click any index.html → Open with Live Server
```

> **Note:** Some projects (LeetCode Metrics, AI Image Generator) require API keys or CORS proxy access. Check their individual README files for setup instructions.
